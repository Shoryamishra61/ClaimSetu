# Theme context

## Compact token summary

- Direction: light-only, calm Indian civic-service interface; independent prototype.
- Font: system sans (`Inter`, `Noto Sans Devanagari`, `Segoe UI`, sans-serif).
- Ink: `#17211B`; muted: `#526158`; surface: `#FFFFFF`; canvas: `#F4F7F3`.
- Primary: forest `#145C3A`; primary hover `#0E472C`; soft green `#E8F3EC`.
- Notice: amber `#8A5200` on `#FFF5D6`; focus: `#FFC107`, 3px solid.
- Error: `#A8201A` on `#FCECEA`; borders: `#C7D2CA`.
- Spacing: 4, 8, 12, 16, 24, 32, 48, 64px.
- Radius: 8px controls, 16px cards; shadow only `0 10px 30px rgba(23,33,27,.08)`.
- Targets: minimum 48x48px; content max-width 760px; mobile floor 320px.
- Motion: 140-180ms opacity/transform; honor `prefers-reduced-motion`.
- Dark mode: deliberately unsupported; public-service legibility is fixed and tested.
