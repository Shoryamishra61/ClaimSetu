|---|---|---|

| 0:09–0:28 | Click **Find what blocks the transfer** | “ClaimPath checks one documented prerequisite using fictional records. It finds that the previous employment has no Date of Exit.” |
| 0:28–0:43 | Show the non-cause; expand technical evidence | “The visible name variation is not the blocker in this fixture. The rule, original value, source and uncertainty stay inspectable.” |
| 0:43–0:59 | Click **Simulate minimum fix** | “The demo adds only the missing Date of Exit and recomputes the same checks. No EPFO account is changed.” |
| 0:59–1:13 | Show result and official next step | “The prerequisite is now met in the simulation. ClaimPath points to EPFO's Mark Exit route before Ravi retries the transfer.” |
| 1:13–1:26 | Architecture frame | “The core is deterministic: fictional evidence, a versioned published prerequisite, counterfactual recomputation and an official handoff.” |
| 1:26–1:39 | Privacy screen | “It asks for no UAN, Aadhaar, PAN, OTP or document. It makes no government API call and never claims approval.” |
| 1:39–1:52 | Hindi journey | “The same focused journey works in Hindi, on a small screen, with keyboard semantics and no AI dependency.” |
| 1:52–1:58 | Official route and fallback | “When EPFO guidance changes, the product must fail safely and send the citizen to the current official route.” |
